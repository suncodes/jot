# 整理项目进展

1. 先用 list_directory 确认用户说的项目对应哪个 content 目录。
2. 用 search 的 directory 参数查询该目录。时间线中的资料更新只作为阅读线索。
3. 用 read 核对重要记录和明确的决定。
4. 用 use_skill 的 path 参数读取 [项目回顾结构](references/outline.md)。摘录有依据的现状与事件，说明遗漏并逐项附出处。
