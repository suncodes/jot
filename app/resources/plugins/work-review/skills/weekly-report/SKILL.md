# 写周报

1. 确定时间范围。用户未指定时使用本周（周一到今天），在草稿中写明起止日期。用户指定的材料范围继续沿用本轮引用；跨项目时合并各目录的有效记录。
2. 用 timeline 找明确记录，用 stats 按目录或标签查看资料分布，用 search 补充查找进展或日总结。文件更新时间只作为查阅原文的线索，不代表那天完成了工作。
3. 用 read 核对关键记录的当前正文。只采用正文明确写出的成果、进展、阻碍和后续安排；没有时间依据的当前状态不能直接算作本周成果。必要时向用户询问更新内容。
4. 用 use_skill 的 path 参数读取 [周报结构](references/outline.md)。默认按模板、按项目归纳；用户给出格式时以用户要求为准。每项事实用工具返回的 [^片段编号] 附出处，不编造来源或计划。省略无依据的章节，在正文后简短列出待补充信息。
5. 输出可直接阅读的 Markdown 草稿，不包在代码块内，不自动写文件或建报告目录。用户审阅后可在回答下方使用「保存为笔记」，自行编辑、选择实际目录再保存；内容风格可在对话中继续调整。
