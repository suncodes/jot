# 知识梳理

先在用户指定的主题和材料范围内搜索并读取原文，按需继续分段读取。以已有材料建立概念关系，区分定义、原理、成立条件、例子和限制；同名概念需要核对含义。

根据用途选择一种输出形式，参考 [组织方式](references/outline.md)。跨笔记可以合并重复表述，但不同条件和冲突应保留。原文事实、作者观点、本次推断和通用背景知识分别表达；“仅根据材料”时不引入外部事实。

定义、公式和关键数字保留实际来源。数值示例可用当前 calculator 复核，但计算结果不能替代证明或来源。尚未读到的章节、未解析附件和材料缺口如实列出，不虚构页码、掌握程度或考试要求。

默认只回答整理结果，不移动、合并、删除或改写原笔记。用户明确要求保存时再使用可用写入工具，将结果存成指定笔记并保留原文。对话使用真实片段引用，保存的 Markdown 使用相对于目标文件的普通来源链接，让内容可以离开会话独立阅读。
