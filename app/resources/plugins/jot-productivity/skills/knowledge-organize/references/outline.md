# 组织方式

按实际用途选择，不要求一次生成全部形式。

- 主题框架：主题、核心概念、概念关系与适用场景。
- 要点卡片：定义、成立条件、典型例子、常见误解、来源。
- 概念对比：共同基础、关键差异、适用条件和资料分歧。
- 复习提纲：主要结论、重要公式或步骤、代表性例子、待补问题。

层级和篇幅由材料决定，不能为了短而删掉必要条件。同一条知识的重复表达可以合并，推论需明确标注。文件更新日期不代表学习日期或掌握程度。

对话引用本轮实际读取的片段；独立文件采用普通相对链接，例如同目录的“原笔记.md”。含空格或特殊字符的路径按 Markdown 链接编码，不写入临时片段编号或猜测的本机绝对地址。
