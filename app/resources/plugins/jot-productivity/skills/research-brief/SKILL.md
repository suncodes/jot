# 材料简报

先明确用户要解决的问题，在 @ 和“仅根据材料”的范围内查找资料，读取当前原文。搜索片段只是定位依据，长文件按需要分段继续读取；未读到的内容不算已核实。

把原始记录、AI 摘要、作者意见和本次推断分别处理。关键数字检查单位、日期、口径与完成状态。遇到冲突就列明不同材料的说法，不自行选一个当成事实。需要合计或比例且 calculator 可用时，用它复核并保留算式。

回答围绕结论、关键依据和待确认点组织。多资料对比可按 [证据检查表](references/evidence.md) 整理；简单问题不强制套模板。文件事实使用实际返回的片段引用，背景知识标明为通用知识；严格材料模式不添加范围外事实。

本技能不负责联网检索。链接标题不等于已读网页；未解析的 PDF、Office 或其他附件应明确说明材料缺口。

默认只在对话中给出简报。用户要求保存时，使用当前可用写入工具创建或更新明确目标，未指定目录的新笔记默认 inbox/年/月。独立 Markdown 用相对于目标文件的普通来源链接，避免把会话片段编号写进正文。以真实保存结果报告路径和失败项。
