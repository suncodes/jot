# 证据检查表

逐项核对影响结论的主张：

| 检查 | 需要回答的问题 |
| --- | --- |
| 来源 | 当前读到哪份原文，具体依据是什么？ |
| 口径 | 日期、单位、统计范围和对象是否一致？ |
| 状态 | 这是计划、讨论、已实现还是已验证的结果？ |
| 冲突 | 另一份材料是否表达不同结论，差别是否能解释？ |
| 缺口 | 哪部分尚未取得原文，哪些只是本次推断？ |

简报可以使用“结论 → 依据 → 分歧或限制 → 建议”的顺序。建议是待采取的行动，不写成已经完成。计算结果附输入来源、公式、单位和必要舍入说明。

来源在对话中用本轮真实片段引用；保存文件时改为普通相对 Markdown 链接。不要补造作者、页码、时间或未经读取的来源。
