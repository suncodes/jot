# OKR 进展

草稿 OKR 提供目标和关键结果，正式日报、周报、月报提供进展事实。仅从本月正式材料提炼已整理的成果，缺少某类报告可以用其他正式材料；没有材料时写明待补，不用未确认草稿或文件修改时间猜进展。

读取当月草稿 OKR 和已有正式 OKR，按真实 O／K 层级组织。每个 O 先给定性整体状态及主要差距；每个 K 写本月实际工作、当前结果与必要后续。没有明确验收标准和权重时，不计算百分比。跨报告同一事实不重复累计，没有直接材料的 K 写“本月暂无直接进展记录”。

面向非研发读者，先解释做了什么、为什么重要和当前到哪一步，再补必要技术细节。保留已存在的人工说明，更新正式目标中相应进展，避免重复添加同名区块。正式目标不存在时可基于草稿目标生成一份正式进展；没有目标依据则先询问。

输出为用户配置正式月份目录下“1、OKR/YYYY年MM月OKR.md”。草稿目标不被改写；不依赖脚本、专用注释标记或数据库状态。完成后返回实际正式文件链接及缺少材料的目标。

从 prepare.months 定位当月 draftOkrPath 和 monthlyPath，结合 prepare.weekly 与 days 的正式报告路径取材；已有正式 OKR 是 prepare.path，本身只提供既有说明，不充当新的完成证据。无目标依据时询问，避免生成空壳进展报告。
