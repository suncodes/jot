# 周报

按所属周周一至周五汇总，当前周截止今天，周末截止周五。优先读取范围内正式日报，必要时按用户范围回读草稿和工程日志；缺日报不等于当天无工作，也不自动用文件更新时间补成果。

按项目或业务主线合并重复叙述，说明本周具体交付、关键验证、当前状态及下周计划。多日连续事项体现过程和最终结果，累计数字只在单位和口径一致且材料支持时相加；讨论、实现、上线和验证分别据实表达。

可以采用“本周重点、主要进展、问题与风险、下周计划、OKR 关联”的结构，用户格式优先。跨月周报读取两个月的相关材料与各自 OKR，保存到实际统计结束日所在月；只选与当前周有关的事实，不将整月进展复制进来。没有材料的部分明确待补，不为凑满五天编造。

prepare.days 列出逐日 reportPath，prepare.months 提供各材料月份的 draftOkrPath；优先核对这些实际文件，缺失的日报在汇报中说明。正式目标沿用 prepare.path，不因周内某一天属于另一月而另外创建一份。
