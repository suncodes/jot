# 月报

历史月取完整月份，当前月截至今天。优先阅读本月正式周报，再用正式日报补覆盖缺口和核实关键数字；同一项工作在多个日报或周报中重复出现只算一项。

跨月周报仅采用目标月份内有依据的事实。按业务主线呈现主要交付、关键改进、验证结果、风险与下月重点；用具体产出和阶段结果体现投入，不堆叠技术名词或把支持工作改写成无依据的经营成果。

对照当月草稿 OKR 说明有关目标的实际进展，无法判断完成比例时使用定性状态。正式月报位于用户配置的正式月份目录下“4、月报/YYYY-MM月报.md”。已有目标先读后按本次任务更新；不改写草稿 OKR，不从上月报告推演本月已完成。

prepare.weekly 提供所有与统计区间相交的工作周报告候选，末周正式周报可能保存在下个月；核对每项 from／to，只采用本月事实。prepare.days 的 reportPath 用于核实缺口，months 的 draftOkrPath 用于对照目标，不能重复累计周报和日报中的同一进展。
