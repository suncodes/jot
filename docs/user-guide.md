# 使用指南

## 第一次运行

选择一个本地目录作为笔记库。新库默认创建工作、生活、成长、健康等顶层内容目录；这些是可修改的普通文件夹。内容库只展示所选模块的数据范围，不把所有系统目录直接作为侧边栏展示。

模型设置可稍后填写。在“设置 → 模型”添加渠道，为渠道填写名称、接口协议、基础地址和密钥，然后在该渠道下添加一个或多个模型。服务地址填写基础地址，不包含完整的请求端点；模型可以设置便于识别的显示名称。

| 接口协议 | 官方基础地址示例 | 请求端点 |
| --- | --- | --- |
| OpenAI Chat Completions | `https://api.openai.com/v1` | `/v1/chat/completions` |
| OpenAI Responses | `https://api.openai.com/v1` | `/v1/responses` |
| Anthropic Messages | `https://api.anthropic.com` | `/v1/messages` |

第三方服务选择其实际支持的协议并填写对应基础地址；Anthropic 基础地址也可带末尾 `/v1`，程序会避免重复。连接测试使用表单中的配置，保存后才会用于助手和后台任务。服务不支持所选协议或推理参数时会报告错误，不会自动切换协议或降低档位重试。

填写渠道连接信息后，可点击“获取模型”，从服务返回的列表中搜索、多选并添加；已添加模型不会重复加入。列表使用当前表单的地址、协议及密钥，已保存渠道留空密钥时沿用该渠道密钥；获取和选择只修改配置草稿，点击“保存配置”后才生效，不会自动改全局默认。

| 接口协议 | 模型列表地址示例 |
| --- | --- |
| OpenAI Chat Completions / Responses | `https://api.openai.com/v1/models` |
| Anthropic Messages | `https://api.anthropic.com/v1/models` |

模型列表按服务实际返回的分页获取；返回数量过大时界面会说明截断，不承诺列出服务未授权的模型。部分代理不提供列表接口，此时可继续“手动添加”。列表可能包含不适合聊天的模型，也不代表模型已支持工具、推理档位或已取得调用权限，添加后仍需测试连接；上下文窗口等能力不会仅凭候选名称自动认定。

上下文窗口可以自动识别或从常见容量选项选择；压缩触发比例可配置，最大输出预算由程序计算。每个模型分别保存上下文窗口、压缩比例和默认推理强度，也可在助手输入区覆盖当前会话的推理档位。切换协议、地址或模型时，需要重新确认上下文窗口和推理强度。

选一个已配置模型作为“全局默认模型”，用于跟随默认的对话和独立后台任务。助手输入框下方的模型选择器按渠道分组，可为当前对话指定模型，或恢复“跟随全局”；选择随对话保存，重启后保持。同一模型标识可以存在于不同渠道，界面会同时显示渠道和模型名称。

切换模型保留原对话及材料引用，从下一轮开始生效，推理强度恢复为新模型的默认配置。生成期间先停止或等待完成，再切换模型。修改全局默认不打断在途回答，也不改变显式选择的其他会话。删除渠道或模型后，相关对话保留历史并提示重新选择，不会自动切换到其他渠道。回答的材料详情可查看当轮实际使用的渠道和模型。

分类、附件摘要和定时日总结使用全局默认模型；对话上下文压缩使用该会话当前模型。没有全局默认时，仍可给某个对话单独选择模型。

## 记录和保存

| 操作 | 默认位置 |
| --- | --- |
| 底部快捷记录或灵感操作 | `ideas/YYYY/MM/` |
| 未选择内容目录的新建笔记 | `inbox/YYYY/MM/` |
| 在明确目录中创建笔记或导入文件 | 选定的 `content/` 子目录 |
| 未指定目录的附件导入 | `inbox/YYYY/MM/` |
| 日总结 | `journal/YYYY/MM/` |
| 附件摘要 | `wiki/sources/YYYY/MM/` |

灵感本身无需归档到内容目录；`inbox/` 存放需要确定目录的资料。待整理入口同时显示目录待处理和已经发起的属性待确认事项，可以分别处理。缺少可选标签不等于所有笔记都必须待整理。

## 内容库和属性

顶部标签页标题支持右键关闭当前、其他、左侧或右侧标签页。批量关闭前会先保存相关编辑；任一保存失败则保留标签页并提示。内容目录支持多级创建、改名和移动。文件或目录可以固定到侧边栏快捷位置；展开、收起和定位按钮用于导航，定位当前文件会展开其上级目录。

文件标题附近的属性按钮可以编辑标签、人物、地点和相关时间。分类管理可以预置词条、改名或合并；它不是新的物理目录树。Markdown 属性写入 frontmatter，附件属性保存为旁置文件。

可以使用外部编辑器修改库内文件。Jot 监听变动并更新索引；外部改名不保证全库引用自动修复。应用内移动或改名会尝试更新可识别的相对引用，并报告未能处理的项。不要依赖索引代替文件备份。

## 使用助手

1. 打开助手，直接提问；需要限制材料时用 `@` 选择文件或目录。
2. 需要特定做法时用 `$` 或 `/` 选择技能。前一轮材料可以沿对话延续，也可以在输入区调整范围。
3. 工具过程、错误和出处可在消息内查看；模型回答不等于实际操作成功，应以工具结果为准。
4. 删除、整篇覆盖等操作通过应用内确认。用户明确给出库外绝对路径时，可以读写库外文件。
5. 上下文接近设定比例时会压缩历史，界面显示相关状态；占比为最近请求的估算。压缩消耗模型请求，不是无限记忆。

日总结根据可用记录和更新材料生成。文件修改时间只能说明“有更新”，不能自动推断当天新增了哪些事实。工作日报、周报、月报和 OKR 采用独立工作报告技能，见 [工作报告指南](work-reports.md)。

## 插件、退出和备份

智能体模块管理 AI 能力；设置中的应用插件管理日记等界面快捷操作。个人日记与工作日记为独立包，可分别启用和配置。工作日记可以可选安装配套工作报告 AI 包，两类插件仍独立启停。

关闭窗口默认进入后台，可在偏好中改为退出程序。后台运行时仍可能执行启用的分析或日总结任务。备份前退出应用，复制整个笔记库；全局偏好另外保存在用户配置目录，详见 [PRIVACY.md](../PRIVACY.md)。
