# 使用指南

## 第一次运行

选择一个本地目录作为笔记库。新库默认创建工作、生活、成长、健康等顶层内容目录；这些是可修改的普通文件夹。内容库只展示所选模块的数据范围，不把所有系统目录直接作为侧边栏展示。

模型设置可稍后填写。AI 功能使用你配置的 OpenAI 兼容模型，地址需与服务的 `/chat/completions` 入口规则一致。上下文窗口可以自动识别或从常见容量选项选择；压缩触发比例可配置，最大输出预算由程序计算。推理强度既可设置全局默认，也可在助手输入区选择当前会话档位。

## 记录和保存

| 操作 | 默认位置 |
| --- | --- |
| 底部快捷记录或灵感操作 | `ideas/YYYY/MM/` |
| 未选择内容目录的新建笔记 | `inbox/YYYY/MM/` |
| 在明确目录中创建笔记或导入文件 | 选定的 `content/` 子目录 |
| 未指定目录的附件导入 | `inbox/YYYY/MM/` |
| 日总结 | `journal/YYYY/MM/` |
| 附件摘要 | `wiki/sources/YYYY/MM/` |

灵感本身无需归档到内容目录；`inbox/` 存放需要确定目录的资料。待整理入口同时显示目录待处理和已经发起的属性待确认事项，可以分别处理。缺少可选标签不等于所有笔记都必须待整理。

## 内容库和属性

内容目录支持多级创建、改名和移动。文件或目录可以固定到侧边栏快捷位置；展开、收起和定位按钮用于导航，定位当前文件会展开其上级目录。

文件标题附近的属性按钮可以编辑标签、人物、地点和相关时间。分类管理可以预置词条、改名或合并；它不是新的物理目录树。Markdown 属性写入 frontmatter，附件属性保存为旁置文件。

可以使用外部编辑器修改库内文件。Jot 监听变动并更新索引；外部改名不保证全库引用自动修复。应用内移动或改名会尝试更新可识别的相对引用，并报告未能处理的项。不要依赖索引代替文件备份。

## 使用助手

1. 打开助手，直接提问；需要限制材料时用 `@` 选择文件或目录。
2. 需要特定做法时用 `$` 或 `/` 选择技能。前一轮材料可以沿对话延续，也可以在输入区调整范围。
3. 工具过程、错误和出处可在消息内查看；模型回答不等于实际操作成功，应以工具结果为准。
4. 删除、整篇覆盖等操作通过应用内确认。用户明确给出库外绝对路径时，可以读写库外文件。
5. 上下文接近设定比例时会压缩历史，界面显示相关状态；占比为最近请求的估算。压缩消耗模型请求，不是无限记忆。

日总结根据可用记录和更新材料生成。文件修改时间只能说明“有更新”，不能自动推断当天新增了哪些事实。工作日报、周报、月报和 OKR 采用独立工作报告技能，见 [工作报告指南](work-reports.md)。

## 插件、退出和备份

智能体模块管理 AI 能力；设置中的应用插件管理日记等界面快捷操作。个人日记与工作日记为独立包，可分别启用和配置。工作日记可以可选安装配套工作报告 AI 包，两类插件仍独立启停。

关闭窗口默认进入后台，可在偏好中改为退出程序。后台运行时仍可能执行启用的分析或日总结任务。备份前退出应用，复制整个笔记库；全局偏好另外保存在用户配置目录，详见 [PRIVACY.md](../PRIVACY.md)。
